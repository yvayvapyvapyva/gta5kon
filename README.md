# Просмотр 3D-моделей авто из GTA SA (DFF+TXD → GLB)

Своих моделей в проекте нет — работаешь только со своими файлами
с компьютера: выбираешь `.dff` + `.txd` в блоке «Конвертер DFF+TXD»,
смотришь результат и забираешь `.glb`.

Веб-приложение: `web/` — Three.js viewer для сконвертированной модели.

## Быстрый старт

```bash
# 1. Сервер: просмотрщик + веб-конвертер
python3 tools/server.py
# открыть http://localhost:8000
```

В блоке **«Конвертер DFF+TXD»** выбери `.dff` + `.txd`, задай **цвет кузова**
(запекается в GLB, как `carcols.dat` — красится крупнейший материал-kind
`paint` без текстуры, тот же критерий, что пикер «Цвет кузова» во вьювере;
тёмная окантовка и хром не трогаются) → кнопка «В GLB и показать»: модель
сконвертируется на сервере, сразу откроется в просмотрщике, а забрать
файл можно кнопкой «Скачать GLB».
Без бэкенда (простой `python3 -m http.server --directory web`) работает
только просмотр своего `.glb` через «Открыть GLB».

CLI-конвертация как раньше:
```bash
python3 tools/convert.py --dff path/to/car.dff --txd path/to/car.txd --out path/to/car.glb
```

## Что сделано

- `tools/convert.py` — парсер RenderWare DFF (фреймы **с именами** — распознан
  фрейм `руль`, `wheel_sr6`, `wheel_*_dummy`, 59 шт.; геометрии, материалы/MatFX,
  specular 0x253F2F6, reflection 0x253F2FC) + TXD (DXT1-декодер на numpy) →
  иерархический `model.glb` (27 МБ, 43 ноды, 30 мешей).
  Резолв деталей — **по именам, без индексов фреймов**: пары `X_ok`+`X_dummy`
  (двери/капот/багажник/бамперы/стекло — сработает на любой SA-модели
  с ванильными именами), таблица кандидатов (оптика, решётка, руль
  включая `f_steer`), эвристики (колесо = ребёнок wheel-дамми, иначе по форме).
  Промах — деталь тихо остаётся в статике.
  `chassis` — статика (кузов, салон, подкапотка); 26 деталей отдельными
  нодами с пивотами дамми как в SA (`door_*`, `bonnet`, `boot`,
  `bumper_front/rear`, `windscreen`, `glass_rear`, вся оптика спереди
  и сзади, решётка, `plate_front/rear` — номера, выцепленные из бамперов
  по материалам `plaka/plakalk`; у дверей/капота/багажника ось петли — в
  `extras.hinge_axis`); `steering` — руль с пивотом в центре;
  `wheel_{rf,lf,rb,lb}_steer` → `wheel_*_spin` — колёса, левая сторона
  отзеркалена; 7 пустых маркеров (`exhaust`, `ped_frontseat/backseat`,
  `petrolcap`, `headlights`, `taillights`, …) для будущего.
  Всего ~950k треугольников, 40 материалов, 17 текстур.
  Координаты GTA (Z-up) переведены в Three.js (Y-up). Материалы как в игре:
  краска/хром (env MatFX → металлик + clearcoat-лак), стёкла (альфа 102–190 →
  BLEND + стекло), фары/фонари (vehiclelights128 → emissive), specular
  vehiclespecdot64 → roughness.
- `web/index.html` / `app.js` / `styles.css` — viewer на Three.js (CDN):
  OrbitControls, сетка, тени, RoomEnvironment-отражения,
  смена цвета кузова, загрузка своего .glb, статистика (треугольники/вершины/габариты).
  Габариты: ~2.08 × 1.68 × 4.72 м.
- Ходовая **как в GTA SA** с управлением **W/S/A/D**: `W/S` — вращение всех
  4 колёс вокруг ступицы (вперёд/назад),   `A/D` — поворот только передних
  `wheel_rf/lf_dummy` (yaw ±35°, с возвратом в центр), руль в салоне
  (фрейм `руль`) всегда повторяет поворот: полтора оборота (540°)
  при полном вывороте вокруг измеренной оси колонки (PCA-нормаль
  к плоскости руля, наклон ~25° — кручение вокруг «прямой» оси давало
  конусное биение до 13 см); пресеты камеры «Кузов / Колесо / Салон»;
  панель «Детали» — видимость каждой part-ноды (задел на открывание
  дверей, отрыв бамперов, битьё стёкол, включение фар).

## Требования

- Python 3 + `numpy` + `Pillow` (для конвертера)
- Браузер + интернет (Three.js грузится с unpkg CDN)
